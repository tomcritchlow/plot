# Sources

## Announcement / Trigger

- [Leo Mehr on X: Ramp AI services announcement](https://x.com/LeoMehr/status/2064717003181707689)
  - The X page was not directly readable outside the logged-in browser, but search snippets identify the post as Leo Mehr announcing Ramp's AI services motion and framing the problem as moving from AI subscriptions to companies that actually run on agents.

- [Ramp Launches Applied AI Solutions](https://www.prnewswire.com/news-releases/ramp-launches-applied-ai-solutions-helping-enterprises-deploy-ai-agents-across-finance-operations-302796179.html)
  - Primary announcement. Useful because Ramp frames the blocker as fragmented finance context across ERPs, procurement tools, docs, spreadsheets, email, approval chains, and employee judgment.
  - Short quote candidate: "AI is easy to demo but hard to deploy in finance."
  - Notes: Ramp lists context extraction, workflow prioritization, system integration, agent deployment, human review, audit trails, and continuous improvement.

## Company Brain

- [Falconer: How to build a company brain](https://falconer.com/guides/how-to-build-company-brain/)
  - Useful articulation of the current "company brain" idea: capture decisions, keep artifacts current, organize canonical/deprecated knowledge, monitor drift.
  - Good foil for the riff because it still starts from knowledge artifacts and maintenance, even while gesturing toward event capture.

## Event Stream / State

- [Martin Fowler: Event Sourcing](https://martinfowler.com/eaaDev/EventSourcing.html)
  - Old software architecture handle for the event-stream argument. Fowler's key move: application state can be reconstructed from stored events.
  - Short quote candidate: "where we are" versus "how we got there."

- [Process Mining Manifesto](https://openresearch.surrey.ac.uk/esploro/outputs/conferenceProceeding/Process-Mining-Manifesto/99862164502346)
  - Near-primary academic source for deriving process knowledge from event logs.
  - Useful line: process mining extracts knowledge from event logs in information systems and helps discover, monitor, and improve processes.

## World Model / Ontology

- [Ha and Schmidhuber: World Models](https://arxiv.org/abs/1803.10122)
  - AI source for "world model" as compressed spatial and temporal representation of an environment that agents can use.
  - The business analogy: a company world model should not only answer questions but allow agents to reason over state, sequence, consequence, and possible action.

- [Palantir: Ontology building](https://www.palantir.com/docs/foundry/ontology/overview)
  - The enterprise software ancestor of this thought. Palantir describes the ontology as an operational layer that connects digital assets to real-world counterparts and can act as a digital twin of the organization.
  - Useful for the noun/verb distinction: semantic elements like objects/properties/links plus kinetic elements like actions/functions/security.
