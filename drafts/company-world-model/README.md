# Model-Entry Bookkeeping

**What this is trying to say:** the "company brain" idea (connect Slack, Jira, Drive; make the company queryable) is directionally right but incomplete — companies aren't short on information, they're short on usable context, and running a company on agents requires something more like a maintained world model than an indexed archive.

**Origin:** sparked by Ramp's AI services announcement.
