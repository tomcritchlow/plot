## RAG And Parametric / Non-Parametric Memory

- Lewis et al., "Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks": https://arxiv.org/abs/2005.11401
- Why it matters: establishes the useful two-layer AI memory vocabulary: parametric memory in model weights plus non-parametric memory in an external index.
- Useful source language:
  - RAG models combine "pre-trained parametric and non-parametric memory for language generation."
  - The paper names provenance and updating world knowledge as open problems for model-only knowledge.

## GraphRAG

- Microsoft Research GraphRAG project page: https://www.microsoft.com/en-us/research/project/graphrag/
- Microsoft Research blog, "GraphRAG: Unlocking LLM discovery on narrative private data": https://www.microsoft.com/en-us/research/blog/graphrag-unlocking-llm-discovery-on-narrative-private-data/
- Why it matters: partial prototype of layer two. GraphRAG precomputes structure from corpora using extraction, network analysis, prompting, and summarization, rather than relying only on nearest-neighbor chunk retrieval.

## Human Memory Models

- Atkinson and Shiffrin, "Human Memory: A Proposed System and Its Control Processes" PDF: https://app.nova.edu/toolbox/instructionalproducts/edd8124/articles/1968-Atkinson_and_Shiffrin.pdf
- Baddeley, "Working Memory: Looking Back and Looking Forward" PDF: https://home.csulb.edu/~cwallis/382/readings/482/baddeley.pdf
- McClelland, McNaughton, and O'Reilly, "Why There Are Complementary Learning Systems in the Hippocampus and Neocortex" PDF: https://stanford.edu/~jlmcc/papers/McCMcNaughtonOReilly95.pdf
- Why they matter: useful source constellation for the analogy that memory is not one store. It involves immediate traces, active manipulation, durable systems, rapid episode-making, and slow pattern extraction.
