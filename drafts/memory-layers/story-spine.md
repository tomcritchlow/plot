# Story spine: The Missing Middle Memory

**Premise:** Useful AI memory accumulates corrected understanding, not just retrievable reports.

**Basis:** [Current manuscript](draft.md), [editorial checkpoint](notes.md), [source notes](sources.md). Updated 2026-09-14.

## Beats

### 1. Six reports; the understanding keeps starting over

- Hypothetical weekly market scan: a competitor changes position, two sources share one origin, an early prediction fails.
- The system retrieves everything. Can it identify which belief should change?

### 2. The missing middle is work, not an undiscovered box

- Context windows already provide an active workspace; [MemGPT](https://arxiv.org/abs/2310.08560) already explored memory tiers.
- Retain the window / kitchen table / basement image. The question is what happens to unfinished understanding between sessions.

### 3. Remembering means revision

- Brian Dell: “Remembering is an act of revision.” [Remembering Futures](https://littlefutures.substack.com/p/remembering-futures)
- A later exception changes the meaning of an earlier observation. Faithful storage alone cannot decide what deserves belief.

### 4. Make the revision concrete

- Hypothetical supplier price cut plus a customer's higher renewal quote: split new-customer pricing from renewal pricing instead of deleting the inconvenient observation.
- Preserve source, scope, date and the evidence that would settle the distinction. Next week's answer should start from that work.

### 5. Prepared structure still needs an owner

- [RAG](https://arxiv.org/abs/2005.11401) provides retrieved evidence; [GraphRAG](https://www.microsoft.com/en-us/research/project/graphrag/) prepares relationships and summaries.
- Neither promise by itself settles which interpretation should be withdrawn. Someone must own promotion, contradiction, revision and expiry.

### 6. Forgetting has several meanings

- Expire a plan; supersede a preference; demote an unsupported claim; delete sensitive information; preserve an old decision without letting it govern today.
- Keep observation, interpretation and instruction distinct. Compression must not turn a complaint into an unauthorized instruction.

### 7. Test whether the next answer starts somewhere better

- Give the system an old policy, a newer exception and a correction. Repeat the question after each.
- Look for a changed answer, explanation, unresolved uncertainty and retirement of the obsolete rule—not merely retrieval of all three documents.

## Landing

- Return to the kitchen table: an arrangement can remain unfinished without being forgotten.
- Demand a revised belief, the evidence that changed it and the decision improved.
