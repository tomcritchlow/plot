## Working Angle

The temptation with LLMs is to convert every spare minute into another active workstream. If the machine can keep working while I am away, why not run three more agents before lunch? This is basically the old poker multi-tabling move: latency feels like waste, so you add tables until attention is saturated.

But the constraint may have moved. The scarce resource is not always technical effort, words, code, or even "output". It is often uncommitted attention: the ability to notice the right opportunity, understand whether it matters, and move when the moment appears.

In corporate finance, financial flexibility is valuable because strategic opportunities are transient and unevenly distributed. You do not know exactly when you will need the capital, but not having it means you cannot capture the opportunity. Maybe the AI work equivalent is "reserve attention capacity".

Poker adds an important discipline: more tables are only profitable while your edge survives. The mistake is adding tables until hard decisions start to feel trivial.

Attention residue sharpens this: every unfinished agent thread leaves a hook in the human operator's head. The parallel with LLM context windows is strong: both humans and models degrade when too many stale traces remain active.

## Tension

Multi-tabling LLMs is genuinely useful. It can create more surface area: scouts, research threads, maintenance tasks, alternate implementation paths. But every running process creates review debt, context debt, and a subtle obligation to return to the terminal.

The HN flow thread gives both sides: for some people agentic coding breaks flow because it becomes prompt/wait/check; for others the new flow is selective multitasking where related workstreams keep attention continuously engaged. The question is whether this is flow as understanding or flow as saturation.

Poker research section: "Of Tokens and Tilt". Use the research carefully: multi-tabling is not inherently bad or pathological, but it is a high-volume operating style where the real question is whether the player's edge survives. Tilt is a strong poker-native frame for judgment drift. In AI work, "token tilt" might be the state where prompting/reviewing/accepting still looks like productive action, but the human operator is no longer making decisions from the same quality of attention.

The walk looks unproductive only if we think work is a utilization problem. If we think work is an opportunity capture problem, the walk might be the productive move.
