## Working Frame

This riff is about agentic commerce, consumer preferences, and the counterintuitive market effects that appear when more of consumer desire becomes legible.

The latest working title is:

> Models Of Desire

The current draft argues that agentic commerce does not merely reveal consumer demand. It helps construct, stabilize, and operationalize preferences that might otherwise remain vague, conflicted, deferred, or strategically hidden.

## Current Revision Bias

The piece should get to the counterintuitive hinge quickly:

> Better search can make markets more efficient and more expensive at the same time.

Then it should use agentic commerce to ask what happens when preferences become easier to elicit, model, disclose, hide, bargain with, and price.
