# How Durable Is the Target?

**What this is trying to say:** Michael Hammer's 1990 injunction not to automate inherited processes needs an update for AI transformation: even the redesigned workflow may expire before it pays back. Jobs are bundles of complementary tasks, so automating one task changes the value, load and failure sensitivity of the tasks around it. A transformation project is therefore a rebundling hypothesis, not merely an automation plan.

The architectural response comes from Parnas: do not turn the flowchart into the system. Isolate the decisions most likely to change and make the action layer replaceable. The managerial response is a Target Durability Audit that maps the task bundle, finds its O-rings, models bottleneck migration and stress-tests the investment across several futures.

**Companion:** [The Target Durability Audit](target-durability-audit.md) is a facilitator-ready framework and chatbot prompt for applying the argument to a real CMO transformation decision.
